작업 1 — scRNA-seq (10x PBMC3k)                              [완료]
  [완료] 1단계  QC → 정규화 → HVG
                2,700 → 2,638 cells, 13,714 genes, HVG 1,838개
  [완료] 2단계  PCA → kNN 그래프 → Leiden → UMAP
                PC 10개, resolution 0.5, 9개 클러스터
  [완료] 3단계  마커 유전자 기반 세포타입 annotation
                Naive T, Memory CD4 T, CD8 T, NK, B, CD14+ Mono, FCGR3A+ Mono, DC, Platelet
  [완료] 4단계  차등발현 + 경로분석 (CD14+ vs FCGR3A+ 단핵구)
                시퀀싱 깊이 편향 발견 → downsampling 보정 (DE 277개 → 50개)
  [완료] 5단계  README (01_scrna_pbmc3k/README.md)

작업 2 — 공간전사체 (10x Visium, 성체 마우스 뇌 coronal)      [진행 중]
  [완료] 1단계  로드 + QC
                2,702 → 2,683 spots, 17,535 genes
  [완료] 2단계  클러스터링 → 공간 도메인 식별
                19개 도메인 (피질 L1~L6, 조롱박피질, 해마 CA1·DG/CA3·neuropil, 시상 2, GABA성 핵,
                시상하부, 편도체 2, 줄무늬체, 백질, 뇌실, 수막)
                인접 spot이 같은 클러스터인 비율 0.724 (무작위 0.064)
  [완료] 3단계  공간 변이 유전자 (Moran's I)
                12,887개 유전자 검정, I >= 0.3인 SVG 1,070개
  [완료] 4단계  deconvolution (NNLS, 마우스 피질 scRNA-seq 레퍼런스 21개 세포타입)
                가상 spot 검증 r = 0.989 / 피질 4개 층 모두 해당 층 뉴런이 1위
                실제 Visium 적합도 R² 0.17 (플랫폼 차이 + 피질 외 영역은 레퍼런스에 없음)
  [진행] 5단계  README (02_spatial_visium/README.md) — 1~4단계까지 작성됨
